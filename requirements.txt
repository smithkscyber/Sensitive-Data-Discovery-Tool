# Versions are pinned so the synthetic corpus in data/raw/ stays byte-identical
# across machines and over time. The answer key records character offsets, which
# are only valid for the exact text Faker produced -- an unpinned upgrade would
# silently invalidate every offset. Upgrade deliberately, then regenerate the
# corpus and the key together.
#
# The same reasoning applies to the NLP stack: Presidio's accuracy comes from a
# spaCy model, and a model upgrade changes which entities are found and how
# their spans are bounded. Every precision/recall figure in the README is tied
# to these exact versions.
#
